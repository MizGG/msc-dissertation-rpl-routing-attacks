# Project Records

This folder contains supporting records from the development process:

- `DEVELOPMENT_HISTORY.md`: chronology and provenance of the implementation.
- `EVIDENCE_INVENTORY.md`: inventory of retained evidence and historical files.
- `HISTORICAL_FILE_TIMESTAMPS.csv`: timestamp record.
- `experiment_notes.txt`: working notes retained for provenance.

These records support the dissertation audit trail. The curated material for submission is in `../Dissertation Evidence Upload/`.
