# Operational Overhead

This folder summarises the completed five-seed Sinkhole-defence campaign. The table reports post-activation application responses, missed responses, parent switches and Cooja radio transmissions.

Radio transmission count is an activity measure, not an energy measurement. ROM and RAM are not reported because the Cooja native target creates host shared libraries rather than embedded firmware images.

```sh
python3 build_overhead_table.py
```
