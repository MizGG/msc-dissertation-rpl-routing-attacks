# Sinkhole Defence Prototype

This Cooja experiment tests a simple rank-consistency rule. A non-root mote rejects a parent candidate that advertises the root minimum rank but does not have the root interface identifier.

There are five matched seeds for normal control, Sinkhole attack and Sinkhole attack with the rule enabled.

The prototype saw the forged rank advertisements, but caused too much parent churn and radio activity in this topology. It is therefore reported as a negative result and a limited defence prototype, not a complete Sinkhole solution.
