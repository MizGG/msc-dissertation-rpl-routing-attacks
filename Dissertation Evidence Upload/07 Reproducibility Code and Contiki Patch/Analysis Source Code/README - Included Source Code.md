# Included Analysis Code

This folder contains the Python code used to produce the dissertation analyses. Working copies remain in the project `scripts/` folder.

- `01 Core IDS and Concept Drift`: features, baseline IDS, cross-attack drift, whole-seed adaptation and summaries.
- `02 Sybil and Online IDS`: Sybil streams and adaptive IDS work.
- `03 Gope Dataset Comparison`: audit and baseline-reproduction scripts.
- `04 Local LLM Explanation Layer`: evidence builder, local Ollama runner and scorer.
- `05 Supporting Validation`: routing-feature preparation and checks.

Older LLM V1 scripts, test fixtures, caches and Finder metadata are not included. Read this code with the Cooja configurations, CSV results and figures elsewhere in the package.
