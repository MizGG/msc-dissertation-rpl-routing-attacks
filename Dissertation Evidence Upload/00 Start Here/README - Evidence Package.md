# Evidence Package


1. `01 Final Figures and Tables` has the figures, tables and results summary used in the dissertation.
2. `02 Validated Cooja Attacks` has the attack code, Cooja files and validation summaries.
3. `03 IDS Drift and Adaptation` has the simulated dataset and the static, drift and adaptation results.
4. `04 Sybil and Adaptive IDS` has the Sybil extension and adaptive IDS work.
5. `05 Robustness Trust and Defence` has the robustness, trust and defence experiments.
6. `06 External Dataset Comparison` has the supplied Gope data analysis.
7. `07 Reproducibility Code and Contiki Patch` has the analysis scripts and relevant Contiki changes.
8. `08 Local LLM Explanation Evidence` has the local Qwen inputs, outputs and checks.

The folder contains final source, configurations, data and results. Build output, caches, old backups and failed trial runs have been removed.
