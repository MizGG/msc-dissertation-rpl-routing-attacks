# Legacy Root Cooja Configurations

This folder collects the Cooja configurations that were originally stored at the project root. It includes local copies of each source file referenced via `[CONFIG_DIR]`, so moving the configurations does not change their Cooja source resolution.

For the dissertation demonstration and recordings, use the clearly named validated configurations in `../../Live Demo and Recording/01 Cooja Simulations/`. These legacy files are retained for provenance and troubleshooting.
