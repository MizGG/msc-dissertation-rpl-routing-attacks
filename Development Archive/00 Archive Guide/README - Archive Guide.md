# Development Archive

This area is not for submission. It provides Finder-friendly access to earlier
drafts, initial IDS studies, intermediate robustness campaigns, LLM prototypes
and build artefacts.

The aliases point to the original raw experiment folders so no evidence is
duplicated or altered. These are retained because negative results and early
versions can be useful when explaining methodological decisions, but they do
not belong in the final evidence zip unless specifically requested.
