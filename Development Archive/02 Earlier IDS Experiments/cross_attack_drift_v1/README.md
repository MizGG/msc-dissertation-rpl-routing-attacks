# Cross-Attack Concept Drift Experiment

This experiment tests whether a routing-window IDS trained on one Cooja attack
family transfers to another attack family. It uses the completed Cooja runs for
blackhole, sinkhole, DIS flooding, grayhole, increase-rank, DIO suppression,
worst-parent and wormhole.

## Inputs

- `features/bh_sh_routing_window_features.csv`: 180 windows from 20 blackhole
  and sinkhole runs.
- `features/additional_routing_window_features.csv`: 540 windows from 60
  additional attack/control runs.
- Window size: 60 seconds.
- Attack windows are labelled only after the 240-second activation point.

## Outputs

- `results/cross_attack_matrix.csv`: full train-family to test-family matrix.
- `results/cross_attack_interpretation.md`: short interpretation of transfer
  failures.
- `diagnostic_with_attack_markers/`: non-primary diagnostic run that includes
  simulator attack markers. This is retained only to reason about feature
  leakage and instrumentation effects.

## Initial Result

Using the default CART model with 57 non-marker routing/window features:

| Training family | In-domain F1 | Mean cross-attack recall | Mean cross-attack F1 | Mean cross-attack FPR |
| --- | ---: | ---: | ---: | ---: |
| blackhole | 1.0000 | 0.0686 | 0.0927 | 0.0000 |
| dio_suppression | 0.7500 | 0.1886 | 0.1988 | 0.0879 |
| dis_flood | 1.0000 | 0.1429 | 0.1429 | 0.0000 |
| grayhole | 1.0000 | 0.1600 | 0.1750 | 0.0000 |
| increase_rank | 0.8364 | 0.2400 | 0.2538 | 0.0615 |
| sinkhole | 1.0000 | 0.0000 | 0.0000 | 0.0000 |
| wormhole | 1.0000 | 1.0000 | 0.4762 | 0.8462 |
| worst_parent | 1.0000 | 0.0000 | 0.0000 | 0.0000 |

There are 56 CART cross-attack train/test pairs. Of these, 37 have zero attack
recall and only 3 have F1 >= 0.8. This supports the concept-drift argument:
models that appear strong in-domain often fail when the attack mechanism
changes.

## Mistake And Failure Analysis

The important failure is not just model choice. The same feature representation
does not expose every attack mechanism equally. Some attacks are obvious in
traffic volume or packet drops, while others change rank, parent choice or
radio topology. Training on one mechanism can therefore learn a narrow
signature rather than a transferable malicious-behaviour concept.

The wormhole-trained model is also instructive. It reaches perfect recall on
other attacks but with very high false positives, so it behaves like an
over-sensitive detector rather than a useful transferable IDS. This is a
different failure mode from the zero-recall static blackhole/sinkhole result.

Attack-marker features are deliberately excluded from the primary IDS result.
They are generated by the simulator instrumentation and would leak ground-truth
implementation details into the classifier. They remain useful for validation,
debugging and explaining why some early experiments looked too easy or too
fragile.

## Dissertation Use

This is the first broad concept-drift result across the professor-paper attack
families. The next defensible step is adaptation: add a small number of
whole-seed runs from the new target attack family and test whether performance
recovers on held-out target seeds without using attack-marker features.
