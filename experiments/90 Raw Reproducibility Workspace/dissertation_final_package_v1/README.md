# Dissertation Final Package V1

This folder assembles the current dissertation-ready writing and evidence
package. It is designed to be copied into the final university document without
changing the preserved experiment outputs.

## Main Files

- `final_dissertation_draft.md`: integrated dissertation text assembled from
  the polished chapter drafts.
- `submission_checklist.md`: practical checklist for moving from this package
  to the final submission.
- `figure_table_index.md`: final list of figures and tables with where each
  should be used.

## Core Claim

The IDS generalises poorly under cross-attack concept drift. Whole-seed
adaptation improves performance, especially for Sybil and several routing
attacks, but failures show that retraining alone is not enough when the feature
representation does not expose the changed attack mechanism.
