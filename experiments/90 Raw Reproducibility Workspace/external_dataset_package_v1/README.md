# External Dataset Package V1

This folder packages the supplied Gope/professor dataset results alongside the
local Cooja dissertation evidence.

Files:

- `external_dataset_summary.md`
- `gope_baseline_results.csv`
- `gope_temporal_family_results.csv`
- `cooja_vs_external_scope_table.csv`
- `how_external_dataset_supports_dissertation.md`

Use this package when writing the methodology/results/discussion sections about
external validation. The key distinction is:

- Gope/professor dataset = external static baseline credibility;
- Cooja = controlled concept drift, adaptation and Sybil new attack-surface
  evidence.
