# Recording Checklist

Record these before the presentation.

## Clips

- Sybil attack Cooja run after 240 seconds.
- Blackhole attack activation/drop evidence.
- Sinkhole advertised-rank evidence.
- One matched control run with no attack marker.

## Minimum Clip Content

Each clip should show:

- Cooja window or log view;
- simulation name/config;
- attack marker or absence of marker;
- timestamp around or after 240 seconds.

## File Naming

Use names like:

- `01_sybil_attack_marker.mov`
- `02_blackhole_drop_marker.mov`
- `03_sinkhole_rank_marker.mov`
- `04_control_no_attack_marker.mov`

Store them somewhere easy to open during the presentation, for example:

`/Users/mizzy/Desktop/dissertation_demo_clips`

## Live Demo Rule

If Cooja is slow during the presentation, do not wait. Show the recording and
then run the quick terminal commands from `terminal_commands.md`.
