# Dissertation Chapter Drafts V1

This folder contains dissertation-ready draft sections based on the current
validated evidence in the repository.

Files:

- `methodology.md`
- `implementation.md`
- `results.md`
- `discussion.md`
- `limitations.md`
- `conclusion.md`
- `figure_table_manifest.md`

These drafts still need final citations, formatting and supervisor-specific
style changes. The claims are intentionally conservative and trace back to the
experiment folders.

Use these as source text, not as the final submitted document. The figures,
tables and CSVs in `experiments/dissertation_results_summary_v1` are the
evidence layer; these Markdown files are the narrative layer built from that
evidence.
